# Запуск бота на GitHub Actions (24/7)

Бот играет на бесплатных раннерах GitHub: задача живёт 5 часов 45 минут, затем её
подхватывает следующая по расписанию (каждые 6 часов). Это единственный способ получить
круглосуточную работу без своего сервера.

## Что нужно знать заранее

- **Репозиторий должен быть публичным.** У приватных репозиториев лимит 2 000 минут
  Actions в месяц, а 24/7 — это около 43 800 минут. У публичных минут неограниченно.
- **Раннер слабее вашего ПК**: 4 vCPU вместо 20 логических ядер, плюс сеть до lichess
  медленнее и с джиттером. В пуле 30+0 это заметно, поэтому `config.github.yml` настроен
  консервативнее (`Threads: 3`, `bullet_horizon: 90`, `bullet_move_overhead: 300`).
  Рейтинг в пуле на раннере, скорее всего, будет **ниже** локального.
- **Только standard и Chess960.** Workflow скачивает один Stockfish; Fairy-Stockfish для
  вариантов (atomic и т.п.) не скачивается. Не регистрируйте облачный инстанс в
  вариантных аренах: Stockfish 19 на неизвестной позиции завершает процесс с
  `CRITICAL ERROR`.
- **Один инстанс на аккаунт.** Не запускайте облачного бота одновременно с локальным:
  два процесса будут наперегонки вызывать соперников и играть в одни и те же партии.
- **GitHub отключает расписание** после 60 дней без коммитов. Раз в пару месяцев делайте
  любой коммит или запускайте воркфлоу вручную (`workflow_dispatch`).
- Расписание — «best effort»: запуск может задержаться на 5–30 минут, поэтому бот
  останавливается сам за 15 минут до следующего окна.

## Установка (один раз)

1. Создайте **публичный** репозиторий на GitHub, например `GlupoZavr`.

2. Добавьте секрет репозитория: `Settings → Secrets and variables → Actions → New repository secret`
   - имя: `LICHESS_BOT_TOKEN`
   - значение: ваш токен `lip_...` из `config.yml`

3. Запушьте код (из каталога с ботом):

   ```powershell
   git remote add origin https://github.com/<ваш-логин>/GlupoZavr.git
   git branch -M main
   git push -u origin main
   ```

   `config.yml` с реальным токеном в репозиторий не попадает (он в `.gitignore`),
   в облако уходит только `config.github.yml` с плейсхолдером.

4. Вкладка `Actions` → workflow `Lichess bot` → `Run workflow` для проверки.
   Через минуту в логе должно появиться `+++ Process Used`, а на lichess бот — онлайн.

5. Дальше всё идёт по расписанию `13 */6 * * *` (UTC).

## Как посмотреть, что бот делал

- Лог текущего запуска: `Actions → Lichess bot → последний run`.
- PGN и `bot.log` каждого запуска: раздел `Artifacts` внизу страницы запуска
  (хранятся 7 дней).

## Как выключить

- `Actions → Lichess bot → ⋯ → Disable workflow`.
- Или удалите секрет `LICHESS_BOT_TOKEN` — бот не сможет авторизоваться.

## Если нужен настоящий 24/7 без оговорок

GitHub Actions не даёт непрерывности: 6-часовые задачи с перезапуском и джиттером сети —
это нормально для арен и блица, но хуже для пули. Если пуля важнее, держите бота на
своём ПК (там 20 ядер и локальная сеть), а облако используйте как «дежурный» режим.
Альтернатива без компромиссов — дешёвый VPS в Европе (`systemd`, 2–4 vCPU, ~5 €/мес).
